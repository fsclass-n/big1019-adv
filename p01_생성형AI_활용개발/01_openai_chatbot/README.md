# 01. OpenAI 챗봇 (유료 / 키 없으면 모의 모드)

```bash
pip install openai
python chatbot.py
```

| 환경 변수 | 설명 | 기본값 |
|---|---|---|
| `OPENAI_API_KEY` | 없으면 모의 모드 | - |
| `OPENAI_MODEL` | 사용할 모델 | `gpt-4.1-mini` |

## 확인할 점

- `history` 리스트에 대화가 쌓이며, 매 요청마다 **전체 대화를 다시 보냅니다.**
- 실제 모드에서는 요청마다 사용 토큰 수가 출력됩니다. 대화가 길어질수록 입력 토큰이 늘어나는 것을 확인하세요.

## 실행 예 (모의 모드)

```
=== 고객센터 챗봇 (모의 모드) ===  종료: quit
나: 환불하고 싶어요
AI: [모의 응답 #1] '환불하고 싶어요'에 대한 답변입니다. 지금까지 질문 1개를 기억하고 있어요.
```
