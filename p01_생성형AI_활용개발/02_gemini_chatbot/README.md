# 02. Gemini 챗봇 & 자동 응답 시스템 (무료)

```bash
pip install google-genai
python chatbot.py        # 대화형 챗봇 (chats API로 대화 기억)
python auto_reply.py     # 샘플 문의 4건을 자동 응답
python auto_reply.py -i  # 직접 문의 입력 (빈 줄 입력 시 종료)
```

| 파일 | 내용 |
|---|---|
| `gemini_client.py` | Gemini 호출 공통 함수. 키 없으면 모의 응답, 429 오류 시 재시도 |
| `chatbot.py` | 멀티턴 대화 챗봇 |
| `faq.json` | 자주 묻는 질문 데이터 (자유롭게 수정해 보세요) |
| `auto_reply.py` | 마스킹 → FAQ 매칭 → AI 답변 → 검증 → 상담원 연결 |

## 실행 예 (모의 모드)

```
문의: 주문한 거 언제 와요? 제 번호는 010-1234-5678 이에요
  ↳ 마스킹: 주문한 거 언제 와요? 제 번호는 [전화번호] 이에요
  [FAQ] 결제 후 평일 기준 1~3일 이내 도착합니다. ...

문의: 회원 탈퇴하면 적립금은 어떻게 되나요?
  [상담원] 정확한 안내를 위해 상담원에게 연결해 드릴게요. (평일 09:00~18:00)
```

## 도전 과제

1. `faq.json`에 "적립금" 항목을 추가하고 결과가 어떻게 바뀌는지 확인하기
2. 키워드 매칭 대신 "질문과 FAQ의 공통 단어 수"로 가장 비슷한 FAQ를 고르게 바꾸기
3. 처리 결과를 CSV 로그(`시간, 문의, 출처, 답변`)로 저장하기
